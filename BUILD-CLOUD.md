# Как собрать установщик в GitHub

Репозиторий: https://github.com/YagodkinGleb/peredyshka

1. Распакуй `peredyshka-update.zip` в отдельную папку.
2. В своём репозитории выбери **Add file → Upload files**. Загрузи содержимое архива, сохранив структуру папок. Обязательно включи `.github/workflows/build.yml`, `package-lock.json` и `src-tauri/Cargo.lock`. При совпадении имён GitHub обновит файлы.
3. Сохрани изменения через **Commit changes**. Для проверки перед заменой основной версии можно выбрать новую ветку и открыть Pull request: сборка запустится автоматически.
4. Для ручной сборки: **Actions → Сборка установщика → Run workflow**, выбери ветку с обновлёнными файлами и запусти.
5. После зелёной галочки открой запуск. В **Artifacts → Peredyshka-Windows** скачай ZIP с установщиком `.exe`.

Workflow сначала запускает проверки логики и браузерные тесты, затем собирает Tauri под Windows. На сервере GitHub есть необходимый компилятор C++.

`artifacts/`, `node_modules/`, `.npm-cache/` и `src-tauri/target/` загружать в репозиторий не нужно. В подготовленном архиве этих папок нет.

Сборка также запускается при отправке тега `v*`. Для такого запуска установщик публикуется в GitHub Releases. Версии в `package.json`, `src-tauri/Cargo.toml` и `src-tauri/tauri.conf.json` должны совпадать; тег выбирай соответствующий им.

Если сборка упала, открой красный шаг. Ошибки `npm ci` обычно означают, что не загружен актуальный `package-lock.json`. Ошибка `--locked` означает несовпадение `Cargo.toml` и `Cargo.lock`: загрузи оба файла из одной версии архива.
