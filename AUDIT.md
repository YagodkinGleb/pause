## Результаты

- `npm test`: 108 прежних актуальных проверок, 11 новых регрессионных сценариев и исчерпывающая проверка бюджета всех связок для каждой секунды от 0 до 3600 — прошли.
- Старые проверки, требовавшие бёрпи, преобладания ног и больше 50 одиночных упражнений, заменены проверками новой согласованной задачи: связки, умеренная длительность, отсутствие повторов и корректный бюджет.
- `npm run test:ui` в установленном Edge: 1440×1080, 1366×768, 800×600, 400×760, 320×568; 120 замен, одно- и двузначные числа, Tab, Shift+Tab, Esc, автоматическая прокрутка текущего шага. Ошибок JavaScript нет.
- `node --check` обоих JS-файлов и `cargo fmt --check` — прошли.
- Версия 1.1.0 согласована в конфигурации, манифестах и lock-файлах. В Actions добавлены Node 24, npm ci и браузерные проверки перед сборкой.

## Что пока не подтверждено

`cargo check` дошёл до компиляции зависимостей и остановился: `link.exe not found`. Visual Studio Installer есть, установленного C++ toolchain он не обнаружил. Поэтому компиляция Rust, создание нового установщика и системные переходы Windows не объявляются проверенными. Сигнатуры используемых плагинов сверены с загруженными исходниками зависимостей.

Последняя старая сборка GitHub Actions — [успешный запуск от 20.08.2026](https://github.com/YagodkinGleb/peredyshka/actions/runs/32372467073). Новый workflow подготовлен локально, но не запускался: подключённый GitHub-аккаунт `gogaboy1` имеет только чтение репозитория; Git Credential Manager не содержит входа, встроенный браузер также не авторизован.

После сборки установщика необходимо проверить на Windows: обычный и скрытый запуск, возврат из перерыва при ранее видимом/скрытом/свёрнутом окне, Alt+Tab, два монитора с разным DPI, меню автозапуска и открытие Boosty в системном браузере. При обновлении со старой версии автозапуск нужно один раз выключить и включить для записи нового аргумента.

Разрыв тиков остаётся эвристикой сна: приложение не получает отдельного сигнала о каждом факте блокировки Windows и не измеряет реальное выполнение упражнений.
