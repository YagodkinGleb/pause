# Передышка

Таймер перерывов для Windows. Разработчик — **Глеб Ягодкин**.
[Поддержать на Boosty](https://boosty.to/yagojeez/donate).

## Что изменилось

- 24 связки из 16 движений: ноги, плечи, спина и корпус. На минутном перерыве доступны 18 связок. Все выполняются стоя на месте, без спортивного инвентаря; для части нужна стена как опора.
- Подготовка, шаги и переходы отсчитываются отдельно. Связка занимает не больше трёх минут, остальной перерыв свободен. Нет прыжков, глубоких выпадов, зашагиваний на стул или заданий на максимум.
- Рамка, колонки и кнопки не меняют положение из-за количества цифр или длины задания. В небольшом окне прокручивается только инструкция; текущий шаг появляется в видимой области автоматически.
- «Заменить» подбирает связку под оставшееся время. Если его меньше 52 секунд, кнопка недоступна.
- Исправлены сохранение работы на 1–4 минуты, пауза, двойной учёт выполнения и смена задания при переключении подсказок.
- Ссылка поддержки находится в подписи разработчика, вне экрана перерыва, и открывается в системном браузере.

## Как пользоваться

Выбери время работы и отдыха, нажми «Запустить». За 30 секунд до перерыва появится предупреждение. Можно отложить его на пять минут, до трёх раз за рабочий период.

На экране перерыва есть 18 секунд, чтобы встать и прочитать движения. Затем следуй подсвеченному шагу. Время — ориентир: двигайся спокойно и остановись, если появилась боль. «Выполнено» завершает перерыв раньше; «Пропустить» и Esc записывают пропуск. Истёкший таймер засчитывается как перерыв, а не как подтверждение физического выполнения каждого движения.

В мягком режиме окно не разворачивается поверх других программ. Когда откроешь его сам, увидишь текущий перерыв. Крестик прячет приложение в трей; выход — через меню трея.

Автозапуск включается отдельно. При запуске с Windows таймер начинает работать в трее. Обычный ручной запуск показывает окно и ждёт нажатия «Запустить». После обновления со старой версии один раз выключи и включи автозапуск, чтобы Windows сохранила новый аргумент `--autostart`.

## Архитектура

Tauri 2: HTML/CSS/JavaScript без фронтенд-фреймворка, Rust для окна, трея, автозапуска, уведомлений и внешней ссылки. Состояние и настройки сохраняются в localStorage WebView2. Сервер и учётная запись приложению не нужны.

- `src/exercises.js` — движения, связки, бюджет времени и колода без повторов.
- `src/app.js` — таймер, переходы, статистика и отображение шагов.
- `src/styles.css`, `src/index.html` — интерфейс.
- `src-tauri/src/main.rs` — системные команды Windows.
- `.github/workflows/build.yml` — проверки и сборка установщика NSIS.

## Разработка и проверки

Для тестов: Node.js 24.

```powershell
npm ci
npm test
npx playwright install chromium
npm run test:ui
```

Если установлен Edge, можно вместо загрузки Chromium выполнить:

```powershell
$env:BROWSER_CHANNEL = 'msedge'
npm run test:ui
```

Для нативной сборки дополнительно нужны Rust stable и Visual Studio Build Tools с C++ и Windows SDK:

```powershell
npm run dev
npm run build -- --ci -- --locked
```

Установщик: `src-tauri/target/release/bundle/nsis/*.exe`. Для сборки используются сохранённые `package-lock.json` и `src-tauri/Cargo.lock`.

Проверки охватывают переходы фаз, сон, отсрочки, паузу, автозапуск с заглушкой системного моста, статистику и повторные клики. Бюджет каждой связки проверяется для каждой секунды от 0 до 3600, включая подготовку и переходы. Браузер проверяет геометрию на пяти размерах окна, 120 замен, доступность текущего шага, клавиатуру и отсутствие ошибок JavaScript. Скриншоты сохраняются в `artifacts/`.

Источники и ограничения подбора движений: [EXERCISES.md](EXERCISES.md). Отчёт по проверке этой правки: [AUDIT.md](AUDIT.md).
